# Editing This Public Collection

This repository contains English learning articles about AI-assisted software development. It is not a product's operating manual.

Read README.md and only the articles relevant to the requested change.

- Write clear English. Keep examples independent of any identifiable internal implementation.
- Distinguish observations, interpretations, illustrative examples, and untested proposals. Do not invent measurements, sources, implementation claims, or model rankings.
- Do not publish credentials, personal or customer data, company materials, internal prompts or thresholds, product-specific routing, exact internal costs, unreleased plans, private repository links, or internal commit identifiers.
- Generalize selected content before writing it here. Do not mirror source repositories, copy their Git history, or assume that all future additions to a source are approved for publication.
- Prefer an existing article over a duplicate. Register new articles in the README once.
- Do not add mandatory review, approval, or draft-state workflows. Use ordinary edits and Git history.
- Do not change repository visibility, licensing, permissions, or product repositories as part of document maintenance unless explicitly requested.
- Preserve unrelated changes. Do not force-push.
- Before publishing an edit, check its relative links, Markdown fences, trailing whitespace, and disclosure scope. Report only the changes and checks actually performed.

Technical verification discussed inside an article is a development pattern, not a mandatory review procedure for this collection.
